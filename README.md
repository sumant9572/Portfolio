## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **Dark Premium Design** | Deep graphite background with electric cobalt blue & violet accents |
| ⚡ **Scroll Reveal Animations** | Staggered fade-up reveals using IntersectionObserver |
| 🃏 **3D Project Cards** | Mouse-follow tilt, animated gradient borders, cursor glow |
| ✍️ **Typewriter Effect** | Rotating role titles in the hero section |
| 📊 **Animated Skill Bars** | Progress bars that animate on scroll into view |
| 🖱️ **Custom Cursor** | Smooth custom cursor with follower on desktop |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop (360px → 1440px) |
| ♿ **Accessible** | Semantic HTML, ARIA labels, keyboard navigation, reduced-motion support |
| 🌐 **No Frameworks** | Pure HTML5, CSS3, and Vanilla JavaScript — zero dependencies |

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML — semantic, single-page structure
├── styles.css          # All styling — design tokens, layouts, animations
├── script.js           # All interactivity — vanilla JS, no frameworks
├── sumant.jpeg         # Profile photo
└── README.md           # You are here
```

---

## 🗂️ Sections

- **Hero** — Full-screen intro with typewriter effect, photo, and CTA buttons
- **About** — Bio, contact details, and stat counters
- **Skills** — Categorised skill tags and animated proficiency bars
- **Projects** — 3D interactive project cards with hover animations
- **Education** — Timeline of academic background
- **Certifications** — Cisco, SimpliLearn, Google AI, LeetCode achievements
- **Contact** — Validated contact form with live error feedback

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup, accessibility attributes
- **CSS3** — Custom properties, Grid, Flexbox, keyframe animations, `@media` queries
- **JavaScript (ES6+)** — IntersectionObserver, RequestAnimationFrame, DOM manipulation
